Hosting, dominios y DNS

Para que una página esté disponible en Internet necesita un lugar donde alojarse y una dirección que permita encontrarla.

Shared hosting

Varios sitios comparten recursos de un mismo servidor. Suele ser una opción sencilla.

VPS

Un servidor virtual con recursos y mayor control que un hosting compartido.

Cloud

Infraestructura distribuida que puede escalar según las necesidades.

Vercel y sitios estáticos

Un proyecto HTML, CSS y JavaScript puede desplegarse en una plataforma como Vercel para obtener una dirección pública.

Dominio y DNS

Un dominio es el nombre legible de un sitio. El TLD es la parte final, como .com o .org. Un subdominio puede ser, por ejemplo, blog.ejemplo.com. DNS traduce nombres de dominio hacia la infraestructura correspondiente. La propagación puede tardar dependiendo de cachés y configuraciones.
