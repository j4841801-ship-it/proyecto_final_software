JavaScript Vanilla

JavaScript es el lenguaje que permite agregar comportamiento e interactividad a una página. “Vanilla JS” significa utilizar JavaScript sin una librería adicional.

HTML

Define la estructura y el contenido.

CSS

Controla la presentación, colores y distribución.

JavaScript

Agrega lógica, eventos y cambios dinámicos.

Variables, funciones y eventos

Las variables almacenan datos, las funciones agrupan instrucciones y los eventos permiten reaccionar a acciones como clics.
