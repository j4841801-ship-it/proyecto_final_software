jQuery

jQuery es una librería de JavaScript creada para simplificar tareas frecuentes del navegador y manipular el DOM con una sintaxis corta.

¿Qué significa $?

El símbolo $ es la función principal que jQuery utiliza para seleccionar elementos y ejecutar operaciones sobre ellos.

$("#mensaje").fadeIn();
$("#menu").slideToggle();

Ventajas y desventajas

  • Sintaxis sencilla.
  • Históricamente ayudó con compatibilidad entre navegadores.
  • Hoy muchas tareas se resuelven con APIs nativas de JavaScript.
  • Agregar una librería extra puede ser innecesario en proyectos pequeños.
